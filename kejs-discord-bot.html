Решение

Telegram-бот с расписанием занятий

21:00каждый вечер бот присылает группе расписание на завтра

Бот берёт расписание с сайта техникума, показывает пары со временем звонков и каждый вечер присылает расписание на завтра.

Как сделано

Студентам приходилось каждый день открывать сайт и искать свою группу. Нужен был бот, который присылает расписание сам.

  • Расписание читается из данных сайта автоматически — никто ничего не вводит руками
  • Время пар подставляется по трём сеткам звонков
  • Сокращённые дни администратор отмечает одной командой
  • Если сайт недоступен — три попытки и показ сохранённой копии
  • Отличает «пар нет» от «расписание ещё не выложили»
  • Работает в облаке круглосуточно; набор тестов без обращения к сети

Telegram Mini App для фестиваля

3 ролигость, партнёр и организатор в одном приложении

Приложение внутри Telegram: регистрация гостей, розыгрыш, раздел для партнёров и админка организатора. Открывается и в обычном браузере.

Как сделано

Дать гостям фестиваля одно приложение вместо бумажных анкет, а организатору — управление участниками и розыгрышем.

  • Экраны на React и TypeScript, бот на Python
  • Регистрация внутри приложения: из Telegram — без пароля, из браузера — по паролю
  • Розыгрыш, партнёрский раздел, админка организатора
  • Сброс кеша по номеру сборки: гости всегда видят свежую версию
  • Выкладка на сервер: домен, HTTPS, автозапуск

Сайт студии танцев с ботом для заявок

8направлений для детей и взрослых: расписание, тренеры, запись

Многостраничный сайт с расписанием и тренерами. Заявки с формы и из бота приходят администратору в Telegram и ведутся по статусам.

Как сделано

Студии нужен был сайт, который объясняет родителям и взрослым, чем занимаются в зале, и доводит до записи на бесплатное пробное занятие.

  • Страницы направлений с расписанием и тренерами; всё наполнение лежит в одном файле
  • Форма записи: заявка сразу уходит администратору в Telegram
  • Бот рассказывает о направлениях, проводит анкету и пересылает вопросы администраторам
  • В боте — список заявок по статусам: ждёт ответа, в работе, записан, отказ
  • Карта и счётчик загружаются только после согласия на cookie
  • Выкладка на хостинг заказчика, бот работает в отдельном облаке; сквозные автотесты
