Серверы и деплойВеб-сервис с мобильным приложением

Вернул автодеплой, который не работал 2,5 месяца

3независимые причины найдены и устранены

После переезда на другой хостинг обновления перестали доходить до сервера. Нашёл три причины — выкладка снова идёт сама после каждой правки.

Как сделано

Команда правила код, но на боевой сервер изменения не попадали: автоматическая выкладка падала с ошибкой.

  • Схема: правка кода → GitHub Actions → копирование на сервер → сборка Docker Compose
  • Причина первая: в настройках остался адрес старого сервера
  • Причина вторая: устаревший ключ доступа
  • Причина третья: сервер принимал подключения только с разрешённых адресов — это нигде не было записано
  • После выкладки автоматически проверяется, что сервис отвечает и отдаёт новую сборку
