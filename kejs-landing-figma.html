Задача

Заказчик просил только HTML, CSS и JS, картинки из самой Figma и точное попадание в макет на компьютере и телефоне.

Страница высотой почти 17 000 px свёрстана на чистых HTML, CSS и JS. Размеры, шрифты и картинки взяты из Figma через API, а не на глаз.

Решение

Что сделано

  • Два макета — 1920 и 360 px; у мобильной версии своя компоновка и порядок блоков
  • Оригиналы картинок и параметры текста выгружены из Figma через API
  • Скрипт сверяет живую страницу с макетом по координатам
  • Планшетных макетов не было — промежуточные ширины собраны самостоятельно
  • Без фреймворков и сборщиков, как просил заказчик
